## Scope

Build `@wirewatch/db` (packages/db) per the "Data model sketch" in
`docs/architecture/overview.md` (the contract):

- Tables: `tenants`, better-auth-compatible `user/session/account/verification`,
  `memberships`, `monitors`, `events`, `incidents`, `incident_events`, `alerts`,
  `magic_links`, `audit_log`.

## Summary of changes

- `packages/db` (`@wirewatch/db`, Drizzle ORM per ADR-0004):
  - `src/schema/` split by domain: `auth.ts` (better-auth core
    `user/session/account/verification` — field-compatible, snake_case
    columns), `tenancy.ts` (`tenants` + `memberships`, role enum
    `owner|admin|member|viewer`), `monitors.ts` (type enum
    `heartbeat|webhook|poll`, `contract_schema`/`sanity` jsonb,
    `ingest_secret_hash` for Phase 2b HMAC), `events.ts` (UNIQUE
    `monitor_id,provider_event_id` = ingestion dedupe), `incidents.ts`
    (UNIQUE `fingerprint` = grouping upsert target + `incident_events`
    link table), `alerts.ts` (UNIQUE `incident_id` = alert-once),
    `magic-links.ts` (hashed tokens, expiry/revocation, `single_use` flag
    for OQ-02), `audit-log.ts`.
  - `tenant_id` FK + index on every tenant-owned table; `tenants` is the
    root (no self-FK); `incident_events` is a pure link table
    (documented exception).
  - `src/client.ts`: `createDb()` factory (postgres.js pool + drizzle +
    schema) + `resolveDatabaseUrl()` (local fallback, prod fail-fast).
  - `src/migrate.ts` + `src/seed.ts`: one dev tenant (`dev-financial`) +
    3 monitors (one per type); idempotent (`onConflictDoNothing`); refuses
    staging/production.
  - `src/schema.test.ts`: 13 contract tests — the three Capability-A
    uniques, key columns, tenant_id coverage.
  - `drizzle/0000_*.sql`: generated migration committed (13 tables,
    4 enums, FKs + indexes). Expand-only from here on.
- `apps/api`: `deps.ts` `getSql()` → `getDb()` (`@wirewatch/db` handle);
  `/ready` db check is now a real Drizzle `SELECT 1` — `isLocal` bypass
  removed, `test`-without-DATABASE_URL bypass kept.
- `package.json`: `db:*` scripts fixed to `bun run --filter @wirewatch/db …`
  (the old `bun --filter pkg run script` form errored — caught live);
  added `db:seed`.
- `Dockerfile.api`: copy `packages/db/package.json` before `bun install`
  (build failed without it — "pruned workspace" error).
- Deviation: the repo had NO git history — initialized at task start with
  a retroactive Phase 1 baseline commit + this task's claim commit.
