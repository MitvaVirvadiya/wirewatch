# project-memory/context/

Stable, curated context for agents. Rarely edited — only by tasks whose explicit
scope is context curation. For everything else, the sources of truth are:

- Product *what/why* → `../../docs/product/`
- Decisions → `../../docs/decisions/` (+ mirror in `../decisions/`)
- Current state → `../../STATUS.md` + `../status/tasks/`
- Evidence → `../../research/` and `../../experiments/`

If you feel the urge to rewrite shared context mid-task: stop, record the
proposed change as an ADR (`proposed`) and flag the human.
